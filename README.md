# 418 Serin Tagaytay Chat Bot & SDK

Customer-Facing & Prospective Guest AI Chat Bot for **Unit 418 Serin East Tagaytay**.
Built as a 100% Cost-Free, AI-Agnostic, Option-First Hybrid Concierge with Google Apps Script (GAS) dual-target compilation.

## Features
- **Hierarchical Option-Based Conversation**: Instant, verified, hallucination-free answers for bookings, rates, parking, smart lock, and building endorsement.
- **Model-Agnostic LLM Adapters**: Chrome Built-in AI (`window.ai`), 0-MB Trilingual Statistical NLU, OpenAI-compatible APIs (Ollama, Groq, LM Studio), and Gemini REST API.
- **Native SQLite Persistence (`node:sqlite`)**: High-performance local conversation, message, tool, and lead storage.
- **Dual-Target Google Apps Script Bundle**: Automated build (`npm run build:gas`) generating `dist/ChatBotCore.gs` and `dist/ChatBotWidget.html`.
- **Zero Cloud Cost**: 100% free tier / local execution.
